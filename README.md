# Collecteur

Page d'installation de l'app Android « Collecteur » :
https://yonigalaxi-blip.github.io/collecteur/

Ce dépôt ne contient pas le code de l'app. Chaque version est une release
avec deux fichiers :

- `collecteur.apk` : l'app
- `version.json` : le manifeste que l'app lit pour se mettre à jour

Lien fixe vers la dernière version :
https://github.com/yonigalaxi-blip/collecteur/releases/latest/download/collecteur.apk
