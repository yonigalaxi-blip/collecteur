# Collector

Page d'installation de l'app Android « Collector » :
https://yonigalaxi-blip.github.io/collecteur/

Ce dépôt ne contient pas le code de l'app. Depuis le 27/09/2026, Collector
s'installe depuis le Play Store, en test interne (adresse Gmail ajoutée à la
liste des testeurs, puis lien de la page).

- `confidentialite.html` : politique de confidentialité (lien de la fiche Play Store)
- `video/journee-en-cours.mp4` : vidéo demandée par Google pour le service « Journée en cours »

Les releases v0.2 et v0.3 (`collecteur.apk`, ancien nom « Collecteur ») restent
pour l'historique : ce n'est plus la façon d'installer l'app.
